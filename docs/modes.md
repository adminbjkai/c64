# Tool modes

> Generated by `scripts/gen-docs.mjs` from `src/modes/index.ts` — do not edit by hand.

c64 ships **32 tools** in 9 categories. Every tool is a pure function that runs in your browser (in a Web Worker above 150 000 characters); none of them makes a network request.

Pretty / Raw is the switch in every pane's option bar: *Pretty* is the formatted or structured result, *Raw* the minified or literal one. Tools marked "—" produce a single output.
