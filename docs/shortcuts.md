# Keyboard shortcuts

> Generated by `scripts/gen-docs.mjs` from `src/shortcuts.ts` — do not edit by hand.

Shortcuts use **Alt+Shift+key** so they never collide with text selection inside the editor or with browser tab shortcuts (the command palette is ⌘/Ctrl+K because that is what everyone expects). Matching is on the physical key, so macOS Option-key symbols never leak into the editor.

## Panes

| Keys | Action |
|---|---|
| `Alt+Shift+R` | Add pane to the right |
| `Alt+Shift+B` | Add pane below |
| `Alt+Shift+D` | Duplicate pane |
| `Alt+Shift+W` | Close pane (the last one always stays) |
| `Alt+Shift+Z` | Reopen the last closed pane |
| `Alt+Shift+Enter` | Maximise / restore the active pane |
| `Alt+Shift+] / [` | Focus next / previous pane |
| `Alt+Shift+N` | Send output on to a new linked pane |
| `Alt+Shift+L` | Toggle stacked / side-by-side layout |

## Editing

| Keys | Action |
|---|---|
| `Ctrl+Enter` | Format now (skip the debounce) |
| `Alt+Shift+C` | Copy output |
| `Alt+Shift+P` | Toggle Raw / Pretty |
| `Alt+Shift+F` | Find in output |
| `Alt+Shift+O` | Wrap / unwrap long lines |
| `Alt+Shift+E` | Explain this input (local helper) |
| `Alt+Shift+M` | Focus the tool selector |

## Workspace

| Keys | Action |
|---|---|
| `Ctrl+K` | Command palette: tools, actions, boards |
| `Alt+Shift+K` | Search tools in the sidebar |
| `Alt+Shift+T` | Toggle dark / light theme |
| `Alt+Shift+/` | Show this shortcut list |

## Inside a pane

| Keys | Action |
|---|---|
| `Tab` to a seam, then arrows | Resize (Shift = bigger steps); double-click a seam to reset / even out |
| `↑ ↓ ← →`, `Enter`, `c`, `p` | In a tree: move, expand/collapse, select, copy value, copy path |
| `+ − 0`, arrows | In a graph: zoom, fit, pan |
| Double-click the pane name | Rename the pane |
| `Tab` in the editor | Inserts a tab character |
